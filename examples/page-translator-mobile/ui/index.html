⚙ Configurações

Sem IA, sem chave, sem Gemini - traduz o roteiro que já existir na página usando um tradutor gratuito. Rápido: não carrega nenhum modelo, nem imagem nenhuma é processada.

Só é usado quando a página ainda não tem NENHUM roteiro (projeto só com imagem "raw") - nesse caso não há texto nenhum pra traduzir localmente. Manda a imagem pra um servidor próprio (sem Gemini, sem IA de terceiros, sessão autodestrutiva - mesma nuvem usada pelo Smart Cleaner Mobile) que só detecta e lê o texto da imagem; a tradução continua sendo feita localmente, pelo mesmo tradutor gratuito de sempre. Desligado por padrão - precisa de internet quando ativado.
